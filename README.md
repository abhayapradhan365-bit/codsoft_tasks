# CodSoft Python Programming Internship

Welcome to my GitHub repository! 👋

This repository contains three Python projects completed as part of my **CodSoft Python Programming Internship**. These projects helped me practice Python programming, problem-solving, and basic application development.

## 📌 Projects

### ✅ Task 1: Calculator

**File:** `calculator.py`

A simple command-line calculator developed using Python.

**Features:**
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- Option to perform multiple calculations
- Input validation

**How to Run:**
```bash
python calculator.py
```

---

### ✅ Task 2: Password Generator

**File:** `password_generator.py`

A Python application that generates a random password based on the length entered by the user.

**Features:**
- Generates random passwords
- Uses uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Allows the user to specify the password length

**How to Run:**
```bash
python password_generator.py
```

---

### ✅ Task 3: To-Do List

**File:** `todo_list.py`

A simple command-line application that helps users manage their daily tasks.

**Features:**
- Add new tasks
- View all tasks
- Remove tasks by number
- Display an empty-list message when no tasks exist
- Handle invalid menu choices
- Validate task numbers
- Exit the application

**How to Run:**
```bash
python todo_list.py
```

**Note:** Tasks are stored temporarily in memory and are not saved after the program exits.
